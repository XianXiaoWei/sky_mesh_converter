# Sky Mesh ↔ GLB 转换器

用于《光·遇》（Sky）`.mesh` 与 `.glb` 文件双向转换的 Python 工具，提供中文菜单、参数多选和版本选择。

基于 **Sky 0.32.2（365939）** 的 `libBootloader.so` 读取逻辑实现。当前 `sky_mesh_converter.py` 为**单文件版**，已内置骨骼动画处理，只需这一份脚本即可运行。

**作者：县小威** · **邮箱：[3661380498@qq.com](mailto:3661380498@qq.com)**

## 功能

- 支持 GLB → mesh、mesh → GLB，主菜单只有两个转换选项。
- 支持 mesh `0x19`～`0x20`，共 8 个版本；mesh → GLB 自动识别版本。
- 参数通过 `● / ○` 显示选中状态，支持多选；结构参数按实际数据自动固定。
- 自动识别文件名后缀，并以 mesh 数据特征进行二次核对；输出按游戏顺序拼接后缀。
- 支持外层 LZ4、位置与 UV 量化、法线、顶点颜色、四组 UV、16/32 位索引和多个 LOD。
- 支持骨骼、每顶点最多四个蒙皮权重、动画片段导出、新增、编辑及重新编码。
- 支持 STEP、LINEAR、CUBICSPLINE 动画输入，支持 24/30 FPS 及自定义采样帧率。
- 支持刚体节点动画、无主几何动画，以及独立附加几何的导出、编辑和回写。
- 保留来源 mesh 数据，满足条件时可逐字节恢复原文件。

## 环境与安装

推荐使用 Python 3.10 或以上版本，已在 Python 3.13 / 3.14 环境验证。支持在 Android Termux 中运行。

下载 `sky_mesh_converter.py` 即可使用。**普通转换只需要 Python 标准库，不需要 APK、游戏 `.so` 或其他转换脚本。**

可选安装 `lz4`，以减小压缩输出的体积：

```sh
python -m pip install lz4
```

未安装时，脚本会使用合法的 LZ4 literal block，仍能被游戏解压器读取，体积通常较大。

## 快速开始

在脚本所在目录运行：

```sh
python sky_mesh_converter.py
```

Termux 完整路径示例：

```sh
python '/storage/emulated/0/Download/建模转换/sky_mesh_converter.py'
```

主菜单：

```text
1. glb转mesh
2. mesh转glb
输入q退出
```

### GLB → mesh

1. 输入 `1`，再输入 GLB 文件路径。
2. 在参数表输入编号切换选中状态；多个编号可用空格分隔。
3. 回车确认参数，进入版本单选表。
4. 选择版本；直接回车默认 `0x20`，输入 `b` 返回参数表。
5. 转换结果保存到输入文件所在目录。

结构固定的参数不能手动取消。默认参数优先来自 GLB 内嵌的来源信息；没有来源信息时尝试识别文件名后缀。

### mesh → GLB

1. 输入 `2`，再输入 mesh 文件路径。
2. 自动读取版本、检查各数据段，并核对文件名参数。
3. 导出 GLB，保留支持的几何、骨骼和动画数据。

LOD0 放在默认场景中；其他 LOD 使用 `MSFT_lod` 和 `extras.sky_lod` 保存。含附加几何时，会另建“附加几何”场景，避免与主模型重叠显示。

## 命令行使用

```sh
# mesh → GLB，自动识别版本和参数
python sky_mesh_converter.py model.mesh

# GLB → mesh，指定回转输出，避免覆盖原始 model.mesh
python sky_mesh_converter.py model.glb -o model_roundtrip.mesh

# 选择位置/UV量化和剥离法线，输出默认带对应后缀
python sky_mesh_converter.py model.glb --version 0x20 --flags "ZipPos,ZipUvs,StripNorm"

# 使用旧布局，取消可切换参数，并关闭外层压缩
python sky_mesh_converter.py model.glb --version 0x1C --flags "" --uncompressed

# 以24 FPS重新采样动画，使用原始float动画轨道
python sky_mesh_converter.py animated.glb --fps 24 --flags "UncompAnim"

# 检查mesh结构，不生成文件
python sky_mesh_converter.py model.mesh --inspect

# 查看帮助
python sky_mesh_converter.py --help
```

| 选项 | 说明 |
| --- | --- |
| `input` | 输入 `.mesh` 或 `.glb`；不提供时启动中文菜单 |
| `-o / --output` | 指定输出路径和完整文件名 |
| `--version` | GLB → mesh 的目标版本，支持 `25`～`32` 或 `0x19`～`0x20`；默认 `0x20` |
| `--flags` | 逗号分隔的参数名；不指定则自动识别；空字符串取消可切换参数，结构参数仍自动固定 |
| `--uncompressed` | 关闭 mesh 外层压缩；与动画轨道的 `UncompAnim` 是两个独立选项 |
| `--fps` | 动画采样帧率 `1`～`240`；未指定时沿用可用的来源帧率或 `sky_fps`，普通 GLB 默认 30 |
| `--inspect` | 输出 mesh 结构信息，不执行转换 |

指定参数不等于为数据添加任意后缀；脚本会检查版本、结构及来源数据是否支持该选项。

## 参数说明

输出后缀按下表顺序拼接。

| 参数 | 作用 | 选择规则 |
| --- | --- | --- |
| `StripGeo` | 无主 LOD 几何 | 根据结构自动固定；附加几何有独立标记 |
| `StripAnim` | 无动画片段，仍可保留骨骼和蒙皮 | 根据动画结构自动固定 |
| `UncompAnim` | 动画使用原始 float，取消动画 LZ4 与 16 位量化 | 有动画片段时可选择 |
| `Add` | 叠加动画变体 | 仅保留来源，当前不可切换 |
| `CompOcc` | 遮挡辅助数据 | 可按条件保留来源或取消；不从新 GLB 生成 |
| `CompEdges` | 边辅助变体 | 仅保留来源，当前不可切换 |
| `CompAdj` | 邻接辅助变体 | 仅保留来源，当前不可切换 |
| `ZipPos` | 位置量化为 10/10/10 位 | 支持的版本中可选择 |
| `ZipUvs` | UV0 / UV2 分量量化为 8 位 | 支持的版本中可选择 |
| `StripUv13` | 剥离 UV1 / UV3 | 支持的布局中可选择 |
| `StripNorm` | 剥离法线 | 支持的版本中可选择 |
| `ForceIdx32` | 强制 32 位索引 | 可选择；旧版本或超出 16 位范围时自动固定 |
| `CopyFrameDelay` | 动画帧复制延迟变体 | 仅保留来源，当前不可切换 |

修改了位置、索引或有效蒙皮后，不能复用旧 `CompOcc` 数据；需要取消该选项。来源保留类参数也会检查数据是否满足保留条件。

## 版本

文件头前四字节是小端版本号，例如 `20 00 00 00` 表示 `0x20`。

| 版本 | 布局差异 |
| --- | --- |
| `0x19 / 0x1A` | 无外层压缩字段，索引固定 32 位，使用旧属性布局 |
| `0x1B` | 增加外层压缩字段 |
| `0x1C` | 增加第二组包围盒数据 |
| `0x1D` | 增加可选属性与量化字段；索引仍固定 32 位 |
| `0x1E` | 增加 16/32 位索引选择字段 |
| `0x1F` | 已确认读取布局与 `0x1E` 相同 |
| `0x20` | 头部增加附加描述区域；本项目生成普通资源时描述数量为 0 |

默认推荐 `0x20`。旧布局不支持的属性组合会被提示或拒绝；旧版本的读取兼容性以 Sky 0.32.2（365939）的兼容分支为依据。

## 输出文件与来源保留

未指定 `-o` 时，结果保存在输入文件所在目录：

```text
GLB → mesh：model_ZipPos_ZipUvs_StripNorm.mesh
mesh → GLB：model._ZipPos_ZipUvs_StripNorm.glb
无参数时：model.mesh / model.glb
```

指定 `-o` 时使用指定的完整文件名，不再自动追加后缀。输出文件已存在时会拒绝覆盖，可用 `-o` 另取名字。

导出的 GLB 带有可选 `SKY_mesh_source` 扩展，保存来源 mesh、校验和及转换信息。标准查看器可以忽略这个扩展。

当来源扩展完整，几何、骨架和动画未修改，版本、参数及外层压缩模式一致，且没有指定重新采样帧率时，可逐字节恢复原 mesh。建模软件删除来源扩展后，仍可转换支持的标准 GLB 数据，但无法保证恢复原始字节。

模型保持游戏原生坐标，不会自动旋转 180 度。

## 附加几何

附加网格和节点使用 `extras.sky_extra_geometry = true` 标记，导出到独立场景。支持修改位置、三角索引、静态节点变换，以及合并多个标记网格。

这段磁盘数据只保存 float32 XYZ 和 u32 三角索引，不保存蒙皮或动画，其游戏用途尚未确认。

- 旧 GLB 没有导出附加段，或编辑软件删除了附加节点时，只要来源扩展完整，回写会保留原附加段。
- 明确删除时，将所有相关附加节点的 `extras.sky_extra_geometry` 设为布尔值 `false`。
- 软件同时删除来源扩展与角色标记后，无法自动恢复附加段。

## 验证

以**能被对应游戏版本的解析器读取**为验证目标，直接执行提取库中的原始 ARM64 代码。模拟文件读取、内存分配等外围服务，实际执行版本检查、外层 mesh 读取、游戏 LZ4、LOD / 附加几何、骨骼及动画读取流程。

| 验证内容 | 结果 |
| --- | --- |
| APK 中全部 5,909 个 mesh 的完整文件解析 | 全部通过 |
| 262 种版本、属性与外层压缩组合 | 全部通过 |
| 13 个已有输出与对照 mesh 的完整解析 | 全部通过 |
| 单文件版 43 项几何、辅助流、动画及附加几何回归 | 全部通过 |
| 仅放单文件脚本、禁用第三方包后的静态/动画转换 | 通过；两个输出通过原始 ARM64 完整解析 |
| 285 个动画 mesh 的来源回转 | 字节一致 |
| 285 个动画 GLB 的 Khronos 标准校验 | 0 错误、0 警告 |

本项目未进行游戏画面验证。上述结果针对 Sky 0.32.2（365939）的解析路径，不代表所有历史或未来客户端均兼容。

开发验证工具所需的 Unicorn、pyelftools 和游戏库不属于普通转换的运行依赖。详细证据可随仓库提供 `逆向说明.md`、`逆向资料/游戏解析验证.md` 及相关报告。

## 使用范围

普通几何、蒙皮、支持的动画和附加几何可以转换；来源保留类参数按上表处理。暂不生成 CompOcc / CompEdges / CompAdj 烘焙、Add / CopyFrameDelay 离线变换、非零头部描述及 morph 动画。

输入超过四个蒙皮权重、多个独立骨架、morph 目标或未解压的 Draco / meshopt 数据时，会明确拒绝。请先在建模软件中整理为支持的结构。

mesh 不包含完整的游戏材质和贴图引用，本工具不自动还原材质或贴图。
